# Financial Econometrics — Seminars & Assignments

This repository contains seminar materials and two final projects from the **Financial Econometrics** course held by the **VEGA Foundation** at **Lomonosov Moscow State University (MSU) in 2024**.

The seminars cover a progression of time‑series and econometric models, including:

- **AR**, **MA**, **ARMA**, **ARIMA** — stationarity and differencing, lag selection, estimation, diagnostics, and forecasting;
- **VAR** and **BVAR** — multivariate time‑series modelling, impulse responses, and forecasting;
- related tools such as unit‑root tests, model diagnostics, and simulation.

The two final projects apply these methods to financial data.
